Install in three steps

1

Open the installer

Windows may show a security warning because this beta is not code signed yet.

2

Allow the beta

On the SmartScreen window, choose More info, then Run anyway.

3

Finish setup

Create your OSL password. OSL will show two recovery items. Save both somewhere offline.

About the Windows warning

SmartScreen warns about new unsigned apps. That warning does not prove an app is safe or unsafe. It means Windows does not recognize the publisher.

If you are not comfortable continuing, stop and inspect the source first. A signed installer and reproducible release builds are still pending.

What to expect

Your accounts stay yours

You sign in through the service's official app or fixed official website. OSL does not ask you to send those passwords to us.

Private mode is a choice

Normal conversations stay normal. OSL Protected mode is for approved OSL recipients.

Recovery is your responsibility

OSL cannot recover your password or secret recovery material from a server.

Calls stay with the service

Voice and video still use each connected service's normal system.

What you need

  • Windows 10 version 1809 or newer, or Windows 11
  • A 64 bit computer
  • 200 MB of free space
  • No external service account is required for the current beta; service adapters are still planned

App availability changes during the beta. Check the release notes before relying on a specific social or email service.
